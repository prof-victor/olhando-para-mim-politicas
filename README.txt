# Olhando para Mim IA — páginas de privacidade

Arquivos:
- `index.html`: política de privacidade
- `exclusao-de-dados.html`: instruções de exclusão de dados

Antes de publicar, revise o conteúdo para garantir que corresponda às práticas reais do aplicativo, especialmente quais dados são armazenados no Supabase e quais dados são enviados ao provedor de IA.

Para GitHub Pages:
1. Envie estes arquivos para a raiz de um repositório público.
2. No repositório, abra Settings → Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione `main` e `/ (root)`, depois Save.
5. Aguarde a publicação. Os endereços serão semelhantes a:
   - `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
   - `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/exclusao-de-dados.html`
